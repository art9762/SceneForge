# Готово и что остаётся

## Завершено в текущем MVP

- Типизированный десятишаговый pipeline и финальная Markdown-сборка.
- CLI/API/Web работают с одинаковым project state и сохраняют старые проекты.
- В UI работают реальный API-контракт, concept index zero, critique и downloads.
- Состояние последней попытки, ошибка и прерывание процесса сохраняются на диск.
- Explicit retry/resume из браузера, API и CLI; один исполнитель на проект.
- Выбор концепции переживает restart; готовые шаги не повторяются.
- Python и desktop/mobile browser regressions, production build и GitHub Actions.

Пять известных high findings остаются в development lint chain; runtime audit
не содержит находок. Версии, upstream advisory и причина отсутствия совместимого
исправления описаны в [dependency audit](dependency-audit-2026-10-23.md).
Проверки local storage не являются подтверждением Windows/NFS/distributed runtime
или качества настоящего LLM. Подробная граница: [lifecycle](lifecycle.md).
